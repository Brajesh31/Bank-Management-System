# Roadmap

## Engineering

- Add Maven or Gradle build metadata and automated tests.
- Extract database configuration and schema migrations.
- Improve input validation and consistent error handling.

## Security

- Remove hardcoded credentials and replace direct PIN storage with a reviewed authentication design.
- Replace SQL concatenation with prepared statements.
- Add authorization, audit logging, TLS, rate limiting, and transaction boundaries.

## Product

- Improve accessibility and responsive desktop behavior.
- Add safe transaction history filtering and export controls.
- Add database backup and recovery documentation.
