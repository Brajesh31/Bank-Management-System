# Glossary

| Term | Meaning |
|---|---|
| ATM | ATM-style flow represented by desktop screens |
| Swing | Java desktop GUI toolkit |
| JFrame | Top-level Swing window |
| ActionListener | UI event callback |
| JDBC | Java Database Connectivity |
| Connector/J | MySQL JDBC driver |
| Statement | JDBC SQL execution interface currently used |
| PreparedStatement | Parameterized JDBC interface recommended for safe SQL |
| Ledger row | Entry stored in the `deposit` table |
| Form number | Registration reference passed between forms |
| PIN | Credential value used in this prototype |
| JCalendar | Date chooser dependency |
| Event Dispatch Thread | Swing thread responsible for UI events and painting |
| PII | Personally identifiable information |
| Idempotency | Repeating a request does not duplicate its effect |
| Migration | Versioned database structure change |
