# Contributing

Contributions should keep this project educational and must never use real banking credentials, card numbers, PINs, or financial data.

## Workflow

1. Create a focused branch.
2. Use a disposable local MySQL schema.
3. Keep connection credentials in an untracked local configuration.
4. Build with the documented classpath and manually exercise affected Swing screens.
5. Update database and security documentation with schema or flow changes.

Pull requests should describe affected screens, SQL/schema changes, verification steps, and any security implications. Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
